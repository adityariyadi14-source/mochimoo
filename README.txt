MOCHIMOO WEBSITE

Upload the contents of this folder to public_html. Keep the images and fonts folders in place.

The site uses HTML, CSS, and JavaScript. The basket and wishlist are saved in the visitor’s browser. Checkout opens WhatsApp, so check the phone number in site.js before publishing.

Product photos are stored in images/. Keep each filename the same as the reference in the HTML unless you also update the image path.
